## 🐛 If Something Doesn't Work

### Panel Won't Open
**Try the original hotkey:**
Press: **⌘ + Shift + Space**

This triggers the old "Manual Analysis" feature to verify the app is working.

### Plan Creation Fails
**Check console logs:**
```bash
# The app is running, check the terminal output
# Look for errors related to Ollama or LLM
```

### Execution Fails
**Common issues:**
1. **Permissions not granted** → Grant in System Preferences
2. **OCR returning empty text** → Try on a screen with more text
3. **Ollama timeout** → The model might be slow first time (loading into memory)
